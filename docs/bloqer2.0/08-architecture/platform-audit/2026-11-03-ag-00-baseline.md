## 4. Hallazgos confirmados

Los seis hallazgos siguientes son anteriores a las modificaciones documentales de esta corrida: no se cambió el código probado. Las prioridades describen riesgo de verificación, arquitectura o documentación; no se comprobó una fuga de datos ni corrupción financiera.

### GA-AG-00-001 — El comando principal deja 36 archivos unitarios fuera de ejecución

- **Prioridad P2, verificación.** La selección es de 190 de 226 archivos; no se trata de cobertura por líneas.
- Fuentes: scripts de [raíz](../../../../package.json), [domain](../../../../packages/domain/package.json), [utils](../../../../packages/utils/package.json), [web](../../../../apps/web/package.json), [validators](../../../../packages/validators/package.json) y [PDF](../../../../packages/report-pdf/package.json).
- Distribución fuera del comando raíz: **domain 3, utils 2, validators 3, PDF 5 y web 23**. El inventario JSON lista cada archivo. PDF tiene suite propia pero no está entre los filtros raíz; validators tiene tests sin script `test`; otros paquetes enumeran listas incompletas.
- Impacto demostrado: las comprobaciones adicionales descubrieron dos aserciones fallidas que la selección habitual no detecta. CI hereda esa selección.
- Corrección pendiente: hacer que las comprobaciones esperadas sean descubribles por el tooling mantenido del proyecto, conservando condiciones especiales RSC y exclusión explícita de integración live. No crear un runner one-off ni incorporar dependencias sin el proceso exigido.
- Cierre requerido: comparar inventario contra selección efectiva y ejecutar las suites incorporadas, sin omitir fallos para obtener verde.

### GA-AG-00-002 — Una prueba de aislamiento aparenta aprobar sin comprobar acceso

- **Prioridad P2, verificación de seguridad.** No demuestra un fallo de permisos del producto.
- Ubicación: [context-isolation.test.ts](../../../../packages/services/src/ai/context-isolation.test.ts), líneas 29–30. Sin `DATABASE_URL`, el test retorna antes de `assert.rejects`; el runner lo cuenta aprobado. Con esa variable, intenta una consulta Prisma real sin requerir flag live.
- Reproducción de esta corrida: proceso sin DB; caso nominalmente aprobado en el log de services, sin ejecutar la comprobación de acceso.
- Corrección pendiente: distinguir explícitamente prueba pura de integración y hacer visible la condición no ejecutada. La prueba real de aislamiento necesita entorno y fixtures adecuados; no se sustituye por un retorno silencioso.
- Cierre requerido: evidencia de skip cuando no hay entorno y comprobación del rechazo en integración aislada, o prueba pura de la política con límites declarados.

### GA-AG-00-003 — CI no ejecuta lint de packages y el chequeo manual encuentra 48 incidencias

- **Prioridad P2, calidad de código/verificación.** Solo web declara `lint`; `turbo lint` no invoca la [configuración raíz](../../../../eslint.config.mjs) para los doce paquetes.
- Evidencia: scripts inventariados y [.github/workflows/ci.yml](../../../../.github/workflows/ci.yml); ejecución manual `node node_modules/eslint/bin/eslint.js packages --format json --output-file ...` con código de salida 1.
- Alcance: 34 archivos afectados; el detalle y reglas están en los artefactos enlazados en §3. No se atribuyen estas incidencias a errores funcionales ni se asume que todas requieren la misma corrección.
- Corrección pendiente: revisar las 48 incidencias y conectar el alcance acordado de lint al flujo mantenido. No desactivar reglas de forma general para silenciar el baseline.

### GA-AG-00-004 — Dos comprobaciones de ayuda fallan por límites de cantidad inconsistentes

- **Prioridad P2, deuda de pruebas.** No acredita un defecto funcional del buscador o de los artículos.
- [search-probe.test.ts](../../../../apps/web/features/help/lib/search-probe.test.ts), línea 125: exige entre 55 y 90 artículos; el catálogo tiene **92**.
- [search-safety.test.ts](../../../../apps/web/features/help/lib/search-safety.test.ts), línea 31: exige como máximo 28 chips; hay **29**. El [test de integridad habitual](../../../../apps/web/features/help/lib/catalog-integrity.test.ts), líneas 71–74, admite hasta **30**.
- La [arquitectura de ayuda](../HELP_CENTER.md) establece fichas por objetivo, etiquetas curadas y un tope de **8 resultados de búsqueda**; no establece esos máximos de 90 artículos o 28 chips. Las pruebas de búsqueda restantes ejecutadas en este conjunto pasaron.
- Corrección pendiente: reconciliar las aserciones con propiedades de contenido, referencias, curación y relevancia verificables. No borrar artículos útiles ni aumentar umbrales solamente para obtener verde. Si se pretende un límite visual nuevo, necesita justificación de UX y el proceso de decisión correspondiente.

### GA-AG-00-005 — La defensa de tenant predeterminada descrita no está implementada globalmente

- **Prioridad P2, arquitectura/control.** La documentación describe filtro/inyección predeterminados; el cliente Prisma disponible es simple y los servicios aplican guards/filtros por recorrido.
- No se demostró consulta cross-tenant, fuga ni autorización incorrecta. No se decide agregar middleware ni refactorizar todos los servicios.
- Evidencia y próximos pasos en el [análisis de arquitectura](./2026-11-03-ag-00-architecture.md). Seguimiento técnico **P-AG00-01** para AG-01.

### GA-AG-00-006 — Exigencia de columna tenant y excepción histórica de hijos sin columna necesitan reconciliación

- **Prioridad P2 documental/técnica.** La regla universal de AGENTS y el modelo de aislamiento contrastan con la aceptación histórica de hijos que heredan tenant por FK al padre.
- El schema contiene **22 hijos/configuraciones sin columna propia**, además de las siete tablas de identidad/raíz/plataforma. Esto no acredita que cada consulta compruebe al padre ni habilita excepciones nuevas.
- Se registraron anotaciones `## Hallazgo` en los dos documentos técnicos afectados y **P-AG00-02**, sin relajar AGENTS, modificar schema ni aprobar migraciones.
- Inventario y límites en el [análisis de arquitectura](./2026-11-03-ag-00-architecture.md). La corrección dependiente queda pendiente de definición explícita.
