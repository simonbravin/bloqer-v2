Certificar, facturar y cobrar

Avance al cliente → factura de venta → CxC → cobranza

Aprobar la certificación no cobra y no crea la factura sola. Solo registra avance certificado. La plata entra cuando emitís la factura de venta y registrás la cobranza en CxC.

1 · Certificar al cliente

1Precondición

PM

Presupuesto Aprobado o Cerrado.

  • Sin baseline no se certifica con normalidad
  • Partidas hoja de la EDT
  • Pública vs Privada cambia el techo
Presupuesto listo

2Nueva certificación

PM

Operación → Certificaciones. Período desde / hasta.

  • Δ% físico y/o $ económico por partida
  • Pública: no superar 100% acumulado
  • Privada: puede superar con nota
Borrador

3Emitir

PM

Emitir la deja inmutable (ISSUED).

  • Ya no se edita
  • El mandante todavía no aprobó
  • No mueve caja
Emitida

4Aprobar o rechazar

PM / Admin

Según respuesta del cliente.

  • Aprobar = avance certificado
  • Rechazar = no se factura esta versión
  • Aprobado ≠ cobrado
Aprobada · o rechazada

2 · Facturar y cobrar

5Emitir factura

Admin / Finanzas

En la certificación Aprobada: Emitir factura.

  • Es manual: aprobar no la crea
  • Genera cuenta por cobrar
  • Facturas emitidas quedan inmutables
Factura + CxC

6Cobrar

Tesorería / Finanzas

CxC del proyecto → Cobrar. No hay Cobrar ahora en el alta de factura de obra.

  • Cuenta de tesorería + fecha
  • Aviso Listo para cobrar (campana)
  • Solo la cobranza confirmada acredita banco
Ingreso de caja

7Contabilizar

Contabilidad

Factura y cobranza generan asientos DRAFT.

  • Contabilizar para los libros
  • Clase: Venta de obra / certificación
  • Anticipo / venta rápida es otro atajo
POSTED

Qué cambia en cada hito

Cert. aprobadaAvance certificado. No hay plata en banco.
Factura emitidaAbre la CxC. Todavía no cobraste.
CobranzaINFLOW en tesorería. Cierra (o parcial) la CxC.
AnticipoAtajo: factura + CxC (+ cobro opcional) en un paso.

Si el cliente no aprueba o no se cobra

Vuelve atrás

  • Rechazo del mandante: esa certificación no se factura; se corrige en una nueva.
  • Factura de venta emitida: solo se anula (no se edita).

Queda trabado

  • Obra pública: Bloqer bloquea si el acumulado supera 100%.
  • Sin presupuesto aprobado/cerrado no arranca el circuito.
  • Aprobar la certificación no genera CxC: hay que Emitir factura.
  • Periodo cerrado o cuenta sin usar: la cobranza se bloquea igual que cualquier tesorería.
