Subcontrato hasta el pago

Paquete de ejecución: certificar → factura → CxP → pagar

Un subcontrato no es una OC. El albañil o el electricista van por este circuito. No se paga eligiendo al subcontratista en un gasto genérico ni creando una orden de compra.

5Aprobar o rechazar

Aprobador

Aprobar habilita la factura. Rechazo es terminal: nueva versión.

  • APPROVED genera CTA a factura borrador
  • Payee = el subcontratista
  • REJECTED no crea CxP
Aprobada · o rechazada

Admin / Finanzas

Revisar y emitir la factura de proveedor.

  • Crea CxP + asiento DRAFT
  • No cambies a quién se le paga
  • Clase: Subcontrato
Factura + CxP

Qué cambia

Aprobar cert.Avance del paquete. Todavía no hay CxP.
Factura emitidaDevengado + cuenta por pagar.
PagoPagado + egreso. Actualiza settlement del subcontrato.
No es OCNo uses compras ni gasto genérico para pagarlo.

Si no se autoriza

Vuelve atrás

  • Certificación en borrador: se edita. Emitida: anular o nueva versión si fue rechazada.
  • Factura en borrador: se revisa y se emite. No se paga el subcontrato desde OC.

Queda trabado

  • Sin Aprobar no hay factura ni CxP.
  • Rechazo terminal: no “des-rechazás”; nueva certificación que reemplaza.
  • Periodo cerrado o sin fondos: mismo bloqueo que cualquier AP.
  • Retenciones y anticipos de subcontrato no están modelados como entidad.
