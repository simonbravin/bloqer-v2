Pagar desde la empresa

Sueldo, reintegro o gasto: factura → CxP → caja

Bloqer no liquida nómina. Un sueldo, un reintegro o un gasto de oficina se registran como factura/gasto ligado a un contacto (Empleado o Proveedor). Siempre existe la cadena Factura → CxP → Pago, aunque se pague en el mismo momento.

1 · Elegir el camino

1Sueldo

Admin / Finanzas

Registro de costo, no liquidación de haberes.

  • Payee = Empleado del Directorio
  • Transacciones → Gasto / factura
  • No uses Solo caja (eso es ingreso)
Gasto mapeado al empleado

2Reintegro

Admin / Finanzas

El empleado adelantó plata y la empresa se la devuelve.

  • Payee = empleado, no el comercio
  • Adjunto del ticket
  • Si es monotributista con factura C: rol Proveedor
Mismo circuito AP

3Gasto / factura

Admin / Finanzas

Alquiler, servicios, proveedor de oficina. Sin obra.

  • Facturas y gastos o Transacciones
  • Clase: Gasto general
  • A quién se le paga = Proveedor o Empleado
Borrador o pago al emitir

2 · Circuito común

4Cargar

Admin

Líneas, fechas y adjunto. Crear factura deja borrador.

  • A quién se le paga (activo + rol)
  • Desc. % opcional antes de IVA
  • Sin proyecto = corporativo
Factura borrador

5Emitir

Admin / Finanzas

Emitir crea la CxP y el asiento DRAFT.

  • Devengado
  • Ya se puede pagar
  • Opción: Emitir y pagar ahora
Factura emitida + CxP

6Pagar

Tesorería

CxP → Registrar pago, o el checkbox al emitir.

  • Cuenta de tesorería + fecha
  • Método y referencia
  • Default = saldo pendiente
Pagado + egreso

7Contabilizar

Contabilidad

El asiento nace en borrador. Hay que Contabilizar para los libros.

  • Hub Contabilidad → Borradores
  • Nunca se auto-posta
  • Reportes solo ven POSTED
Asiento POSTED

Qué cambia en cada hito

BorradorTodavía no hay CxP ni caja.
EmitidaDevengado + cuenta por pagar.
PagoPagado + egreso de tesorería.
ContabilizarEntra a libros gerenciales.

Si no se puede pagar

Vuelve atrás

  • Factura en borrador: se edita. Una vez emitida, se anula (no se edita).
  • Contacto que no aparece: asignale rol Proveedor o Empleado y que esté activo.

Queda trabado

  • Fondos insuficientes en la cuenta: Bloqer bloquea Emitir y pagar ahora / el pago.
  • Periodo contable cerrado en esa fecha.
  • Movimiento ya conciliado: hay que desemparejar antes de cancelar el pago.
  • No uses Solo caja para “pagar” un sueldo o reintegro (eso es ingreso).
